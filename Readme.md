# Taller 01 POO 2026-II

## Descripcion del proyecto

Este proyecto corresponde al Taller 01 de Programacion Orientada a Objetos. El programa simula un sistema de control para el grupo de WhatsApp de POO, donde solo pueden ingresar estudiantes que esten inscritos oficialmente en un paralelo del curso.

El sistema permite cargar alumnos y solicitudes desde archivos de texto, procesar solicitudes de ingreso, registrar admitidos y rechazados, administrar la lista de alumnos, generar reportes y mostrar estadisticas basicas.
